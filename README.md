# msh-image-relay

MindStackhouse 社群自動發文的圖片中繼站。

Instagram 的 API 只接受公開的 https 圖片網址，不收本機檔案，所以圖卡與影片在發布前要先躺在一個 IG 抓得到的地方。這個 repo 就是那個地方。

## 運作方式

備料排程每晚把隔天要發的成品放進來，路徑是 `YYYY-MM-DD-主題/01.png` 這種形式。成品同時會嵌進 Notion 社群行事曆那一格，讓 Glenn 在手機上看過再決定核不核准。

發布成功之後，發文腳本會把該次的目錄刪掉。所以這裡平常應該是空的，看到有東西代表有一則正在等發或剛出問題。

## 注意

這個 repo 是公開的，只放本來就要公開發出去的圖卡與影片，不要放任何其他東西。

raw 網址有大約五分鐘的 CDN 快取，刪除之後網址還會讀得到一陣子，這是正常的。IG 在建立容器那一步就已經把圖存進自己的 CDN，中繼站消失不影響已發布的貼文。

規格書在主 repo `100_Todo/projects/2026-08-25_社群自動發文系統_規格書.md`。
